# Istifa Do — NEET Universe

A playful NEET study website with meme-inspired copy, focus music controls, a curly-haired future-doctor character, and Physics, Chemistry and Biology portals.

## Run locally
1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.
4. Keep `index.html`, `style.css`, `app.js`, and `future-doctor.png` together in the same folder.

## Mobile
The layout includes responsive CSS for smaller screens. Test the subject portals and music controls on your target browser before publishing.


## NEET chapter checklist
The dashboard includes Physics (20 units), Chemistry (20 units), and Biology (10 broad units) with checkboxes and progress saved in browser localStorage. This is a study-tracker outline; compare exact topic scope with the current official NEET UG syllabus before relying on it for exam coverage.
